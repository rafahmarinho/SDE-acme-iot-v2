Quero desenvolver esta aplicação, com aparência e funcionamento próximos de um produto real.

Use inglês como idioma padrão em todas as telas, mensagens, relatórios e dados de exemplo.

Use versões atuais e estáveis das tecnologias e Supabase para PostgreSQL, login por e-mail e

senha, arquivos e atualizações em tempo real. Quero as telas funcionando e os dados

persistidos, com integrações externas simuladas. Organize o projeto em telas, componentes,

serviços e acesso ao banco. Inclua login, recuperação de senha, perfil, configurações, busca,

filtros, estados de carregamento e mensagens de erro. Adapte a navegação aos perfis de

usuário.

A plataforma IoT vai se chamar ACME IoT e deve usar React Native com Expo, Expo Router e

TypeScript para Android, iOS e web, com uma API TypeScript na Vercel. Use pnpm. Use um visual

claro com detalhes em índigo, cards de dispositivos e navegação por organização, prédio e

sala. Crie telas de dashboard, prédios, salas, cadastro e detalhe de dispositivos,

automações, alertas, eventos, firmware, integrações e equipe. Inclua termostatos, tomadas

inteligentes e sensores de temperatura, umidade e ocupação. Permita cadastrar dispositivos

por QR code ou código manual, consultar leituras, mudar a temperatura e ligar ou desligar

tomadas. Mostre o estado desejado e o estado informado pelo dispositivo. Crie automações

simples de condição e ação, com intervalo entre execuções, histórico e notificações. Simule

dispositivos offline, bateria baixa, reconexão e atualizações de firmware com progresso e

rollback. Use serviços HTTP para simular a comunicação, sem depender de um broker MQTT. Tenha

perfis de proprietário, administrador, operador e visualizador. Pode criar um dashboard com

os elementos em 3D dentro de uma sala, para simular visualmente melhor!

Prepare dados de demonstração com duas organizações e vinte dispositivos. Inclua uma área

para escolher cenários, avançar a simulação, consultar eventos e reiniciar os dados. Os

resultados devem aparecer nas telas e continuar salvos após recarregar a aplicação. As

versões web e mobile devem compartilhar o mesmo projeto Supabase. No celular, adapte os

formulários ao toque, pause as atualizações em segundo plano e mostre os últimos dados como

leitura offline. Retome as atualizações quando a conexão voltar; ações de controle exigem

conexão. Entregue o código completo, configuração do banco, dados iniciais, exemplos de

variáveis de ambiente e um README com os passos para rodar e publicar a versão web e a API na

Vercel. Inclua as versões Android e iOS e instruções para gerar os pacotes nativos. Confira

os fluxos principais, mantenha a implementação objetiva e conclua as páginas e ações

descritas.
